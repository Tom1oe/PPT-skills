# 布局系统参考文档

## 幻灯片尺寸基准

- **标准宽屏 16:9**: 13.333" × 7.5"
- **坐标系**: 左上角为原点 (0, 0)，向右为 X 正方向，向下为 Y 正方向
- **单位**: 英寸 (Inches)
- **标准边距**: 左右 0.6"~0.8"，上 0.5"，下 0.4"

## 布局模板全集（20 种经典版式）

### 1. 结构与篇章导航类

#### `catalog_grid` — 目录索引页
适用场景：大会演讲、工作汇报目录、论文结构索引（2~4部分）
```
┌───────────────────────────────────────┐
│ ┌─┐                                   │
│ │目│  Part 01 研究背景   Part 02 研究方案  │
│ │ │                                   │
│ │录│  Part 03 研究成果   Part 04 研究总结  │
│ └─┘                                   │
└───────────────────────────────────────┘
```

#### `section_header` — 章节转场页
适用场景：篇章过渡、大章节启程、PART 标签
```
┌───────────────────────────────────────┐
│        ┌─────────────────────┐        │
│        │     [ PART 01 ]     │        │
│        │    论文研究背景      │        │
│        └─────────────────────┘        │
└───────────────────────────────────────┘
```

#### `cover_fullimage` — 全幅封面
适用场景：全屏背景图 + 居中主标题
```
┌───────────────────────────────────────┐
│          [全幅背景图 16:9]             │
│                 01                    │
│             年度工作汇报               │
│           Work Summary 2024           │
└───────────────────────────────────────┘
```

#### `cover_split` — 分割封面
适用场景：左侧主视觉大图 + 右侧标题及格言
```
┌──────────────┬────────────────────────┐
│              │    "厚积而薄发"         │
│  [左侧大图]  │              01        │
│   (立绘/山水) │    年度工作汇报        │
│              │    路虽远 行则将至      │
└──────────────┴────────────────────────┘
```

#### `section_divider` — 章节分隔页
适用场景：左右对半结构，左侧配图，右侧大号序号与章节名
```
┌───────────────────┬───────────────────┐
│                   │      02           │
│  [左侧背景图]      │  不足分析与改进   │
│                   │  Analysis & Plan  │
└───────────────────┴───────────────────┘
```

### 2. 逻辑与思维中枢类

#### `central_radial_lightbulb` — 思维发散中枢页
适用场景：核心概念发散、根因分析、问题拆解（中心灯泡/问号 + 4个发散节点）
```
┌───────────────────────────────────────┐
│ 发现问题 ──────── ┌─────┐ ──────── 分析问题 │
│                 │  ?  │               │
│ 解决问题 ──────── └─────┘ ──────── 总结思考 │
└───────────────────────────────────────┘
```

#### `planetary_orbit` — 多维卫星轨道页
适用场景：领导力模型、多维素质评估、核心竞争力（中心主题 + 5~6 卫星环绕 + 详情卡片）

```
┌───────────────────────────────────────┐
```

#### `content_centered` — 环形辐射页

### 3. 层级、进阶与流程类

#### `pyramid_hierarchy` — 金字塔层级页
适用场景：马斯洛需求、架构层级、漏斗转化（左侧说明 + 右侧分层金字塔 33%/66%/99%）
```
┌───────────────────────────────────────┐
│ ■ 基础执行层               /  33%  \  │
│   说明文字...             /─────────\ │
│ ■ 流程协同层            /    66%    \ │
│   说明文字...          /─────────────\│
│ ■ 战略决策层         /      99%      \│
└───────────────────────────────────────┘
```

#### `stepped_stairs` — 阶梯上升进阶页
适用场景：能力进阶、技术演进路线、4 阶段成长阶梯
```
┌───────────────────────────────────────┐
│                        ┌────┐ [04]    │
│                 ┌────┐ │    │ 专家    │
│          ┌────┐ │    │ │    │ 进阶    │
│   ┌────┐ │    │ │    │ │    │ 骨干    │
│   │    │ │    │ │    │ │    │ 新人    │
│  [阶段1] [阶段2] [阶段3] [阶段4]      │
└───────────────────────────────────────┘
```

#### `process_arrow` — 流程冲刺目标页
适用场景：多阶段推进、关键路径指引、最终冲刺核心竞争力
```
┌───────────────────────────────────────┐
│ 01 领导力  03 协调力  05 团队协作     │
│ ────────────────────────► ┌─────────┐ │
│ 02 专业技能 04 创新力  06 执行力   │核心竞争 │ │
│                           └─────────┘ │
└───────────────────────────────────────┘
```

#### `timeline` — 横向时间轴页
适用场景：发展历程、里程碑事件、时间推进
```
┌───────────────────────────────────────┐
│  2021          2023          2025     │
│  起步阶段      快速扩张      生态构建 │
│ ───●─────────────●─────────────●───── │
│    2022             2024              │
│    技术攻关         全国布局          │
└───────────────────────────────────────┘
```

## 布局选择全景决策树

```
输入内容
  ├─ 目录索引 (catalog) ──────────────► catalog_grid
  ├─ 章节过渡 (section / break) ──────► section_header / section_divider
  ├─ 封面设计 (cover)
  │   ├─ 全屏大图/风景 ────────────────► cover_fullimage
  │   └─ 左图右文/立绘 ────────────────► cover_split
  ├─ 结构与思维 (mindmap / hierarchy)
  │   ├─ 金字塔/层级漏斗 ──────────────► pyramid_hierarchy
  │   ├─ 中心发散/根因分析 ────────────► central_radial_lightbulb
  │   └─ 核心能力/卫星轨道 ────────────► planetary_orbit
  ├─ 路径与流程 (timeline / process)
  │   ├─ 台阶上升/能力成长 ────────────► stepped_stairs
  │   ├─ 冲刺推进/目标终点 ────────────► process_arrow
  │   └─ 标准横向时间轴 ──────────────► timeline
  ├─ 方案对比 (comparison)
  │   ├─ 双圆形方案/定价 ──────────────► two_options_circle
  │   └─ 左右分栏对比 ────────────────► comparison
  ├─ 数据展示 (data)
  │   ├─ 进度/环形卡片 ────────────────► data_stats
  │   └─ 柱状/折线/雷达图 ─────────────► data_chart
  └─ 多条目内容 (content)
      ├─ items = 5~6 ─────────────────► content_grid_2x3 / content_centered
      ├─ items = 3~4 ─────────────────► content_grid_2x2
      └─ items ≤ 2 + 人物配图 ─────────► content_sidebar
```

## Zone 类型说明

| 类型 | 说明 | 用途 |
|------|------|------|
| `TEXT` | 文本框 | 标题、段落、副标题、项目符号 |
| `IMAGE` | 图片区域 | 照片、插图、立绘 |
| `CHART` | 图表/图元 | 柱状图、折线图、金字塔、阶梯台阶 |
| `ICON` | 图标区域 | 编号圆形、通用矢量图标 |
| `DECORATOR` | 装饰元素 | 发散中枢、圆角面板、分隔线、光效 |
| `NUMBER` | 大号数字 | 章节编号、核心指标 |
| `BACKGROUND` | 背景层 | 全幅背景图 |
